## Configurar recorrência

```ajuda
id: recorrentes.configurar
tooltip: "Crie modelos de transações periódicas (rendas, seguros, serviços mensais). Ao criar um modelo com data de fim, o sistema tenta gerar de imediato as transações de todo o período; sem data de fim não as gera por este fluxo. Editar o modelo não volta a gerar as transações."
ecras: [recorrentes]
perfis: []
fontes: [src/pages/RecurringTransactions.tsx]

```

Crie modelos de transações periódicas (rendas, seguros, serviços mensais), definindo frequência, dia do mês, início e fim opcional. Sem data de fim, este fluxo não gera transações. Ao criar um modelo com data de fim, o sistema tenta gerar de imediato as transações de todo o período; editar o modelo não volta a gerar as transações.
