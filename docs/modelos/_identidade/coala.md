# Coala Festival Portugal — identidade

**Origem.** Portal coalafestival.pt, projeto Lovable bef9c59c-c2a4-453d-9aec-dae7d16c9171, ficheiro `src/styles.css` (`:root`; o ficheiro cita o manual de marca: Creamy White / Edgier Black / Landscape Grey), lido a 24/10/2026.

**Usa-se em.** Tudo do Coala: fecho, Early Bird, tráfego, BP, apuramentos.

## Cores

| Papel | Nome no manual | HSL | Hex |
|---|---|---|---|
| Fundo | Creamy White | 36 100% 98% | #FFFBF5 |
| Texto, títulos, número-chave | Edgier Black | 0 0% 8% | #141414 |
| Labels / eyebrows | Landscape Grey | 0 0% 56% | #8F8F8F |
| Texto secundário (grey escurecido para contraste) | — | 0 0% 40% | #666666 |
| Blocos secundários | secondary | 36 33% 94% | #F5F1EB |
| Linhas e separadores | border | 36 30% 89% | #EBE5DB |

A marca é só preto / creme / cinza. O âmbar (`--gold`) existe no CSS mas foi removido da identidade — não usar.

## Tipografia

- Títulos: Lausanne, peso 900, caixa alta, tracking -0.02em.
- Títulos de secção em serif: Inferi, peso 500, caixa mista.
- Corpo: Lausanne 400.
- Eyebrows / metadados: PP Fraktion Mono Bold (fallback IBM Plex Mono), caixa alta, tracking 0.18em.
- Fontes locais em `public/fonts` do portal; em xlsx usar Arial/Helvetica como fallback.

## Notas

- Sempre claro; dark mode desactivado por decisão de design.
- Cantos quase rectos (0.125rem).
