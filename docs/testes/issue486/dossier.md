As escolhas BP da linha continuam a ser eliminadas, exigindo nova seleção de cada parcela.
2. `ads_invoice_maintenance_v1(...,'preflight',{company_id})` é uma leitura exclusivamente service_role, com gate enabled antes de efeitos Storage. Não adquire claim, não altera revisão/ciclo/tarefas, não substitui list/ack/retry e não ativa a feature. O handler revalida acesso e manage_transactions antes das operações internas.
3. A atestação diferente válida chama o classificador TikTok após validar a prova financeira, dentro do contexto privado de attest autorizado pela guarda de linhas. Assim a UI recebe carreira apenas após prova de conta, antes da primeira escolha de plano. A revisão já incrementada pela atestação vincula essa classificação; a repetição idêntica mantém o no-op.
